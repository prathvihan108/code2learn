# Packages
In Java, packages are used to organize and categorize related classes and interfaces. The packages you mentioned—java.lang, java.util, java.io, and java.awt—are some of the core packages provided by the Java Standard Edition (SE) API. Here's a brief overview of each:

    java.lang: This package provides fundamental classes that are automatically imported into every Java program. It includes classes like Object (the root class for all Java classes), String (for manipulating strings), Math (for mathematical operations), and others.

    java.util: This package contains utility classes and interfaces, including data structures like lists, sets, maps, and various utility classes for handling dates, times, and other common tasks. Examples include ArrayList, HashMap, Date, and Random.

    java.io: The input/output (I/O) package is used for reading and writing data. It includes classes for working with files, streams, readers, writers, and more. Some classes in this package are File, InputStream, OutputStream, Reader, and Writer.

    java.awt: The Abstract Window Toolkit is used for creating graphical user interfaces (GUIs) in Java. It includes classes for windows, buttons, text fields, and other GUI components. Note that in modern Java development, the Swing framework (javax.swing package) is more commonly used for GUI development.

# Object class #

    The Object class is at the root of the Java class hierarchy, and it is the superclass for all Java classes. As a result, every class in Java inherits the methods defined in the Object class. Here are some of the commonly used methods provided by the Object class:

    public String toString():

    Returns a string representation of the object.
    This method is often overridden in subclasses to provide a meaningful string representation of the object.

public boolean equals(Object obj):

    Indicates whether some other object is "equal to" this one.
    By default, the equals method compares object references. Subclasses often override this method to provide custom equality comparisons.
