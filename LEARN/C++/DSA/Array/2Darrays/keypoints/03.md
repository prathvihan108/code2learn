In C++, when you pass a `std::vector` to a function, a copy of the vector is typically made. By default, C++ uses value semantics for function arguments, which means that a copy of the vector is created and passed to the function. This copy includes all the elements of the vector, and any modifications made to the vector within the function will not affect the original vector that was passed.

Here's an example to illustrate this behavior:

```cpp
#include <iostream>
#include <vector>

void modifyVector(std::vector<int> vec) {
    vec.push_back(42);  // Modify the copy of the vector
    std::cout << "Inside the function: vec size = " << vec.size() << std::endl;
}

int main() {
    std::vector<int> myVector;
    myVector.push_back(10);
    myVector.push_back(20);
    myVector.push_back(30);

    modifyVector(myVector);

    std::cout << "Outside the function: myVector size = " << myVector.size() << std::endl;

    return 0;
}
```

Output:
```
Inside the function: vec size = 4
Outside the function: myVector size = 3
```

As you can see, the modifications made to the vector inside the `modifyVector` function did not affect the original vector outside the function.

If you want to avoid the copy and work directly with the original vector, you can use a reference or a pointer to the vector as the function parameter. For example:

```cpp
void modifyVector(std::vector<int>& vec) {
    vec.push_back(42);  // Modify the original vector
    std::cout << "Inside the function: vec size = " << vec.size() << std::endl;
}
```

In this case, the modifications made to the vector inside the function will be reflected in the original vector outside the function.
